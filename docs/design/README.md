# 基本設計書（機能別）— afterglow_app

**作成日**: 2026-11-05
**作成方法**: 現行コード（`lib/`, `functions/src/index.ts`, `firestore.rules`, `storage.rules`）からの逆起こし

本ディレクトリは、実装済みの機能を機能単位で整理した基本設計書である。仕様の正典は
[要件定義](../要件定義.md)・[詳細設計](../詳細設計.md) であり、本書は「現在のコードが実際にどう動くか」を記録する。
両者に差異がある場合、本書はコードの挙動を、正典は意図された仕様を示す。差異は各書の「既知の制約・課題」に記載する。
